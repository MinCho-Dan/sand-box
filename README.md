# 이세계전사 김대원

> 단기 4361년. 유례없는 핵전쟁으로 폐허가 된 대륙에서 두 발로 서 있는 유일한 생명체, 김대원.
> 빈 마트를 돌아다니며 연명하던 그의 눈앞에 알 수 없는 현상이 일어난다.
> 더는 볼 수 없는 싱그러운 들판이 비치는 동그란 유리창에 손을 대는 순간 —

브라우저에서 바로 돌아가는 탑다운 액션 게임입니다. PC와 모바일 모두 지원합니다.

**▶ [지금 플레이하기](https://gyujik.github.io/isekai-kimdaewon/)**

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | `WASD` / 방향키 | 왼쪽 화면을 끌어서 (가상 스틱) |
| 공격 | `J` / `Space` | `공격` 버튼 |
| 회피 | `Shift` | `회피` 버튼 |
| 시작·진행 | `Enter` | 화면 탭 |

모바일은 **가로 모드**를 권장합니다. 세로로 들면 안내 화면이 나옵니다.

## 게임 규칙

- **허기** 게이지가 계속 줄어듭니다. 0이 되면 체력이 깎이니 통조림·식량을 챙기세요.
- **회피**는 무적 프레임이 있습니다. 적의 탄막은 회피하거나 렌치로 쳐낼 수 있습니다.
- 적을 처치하면 확률적으로 식량과 구급킷을 떨어뜨립니다.

## 스테이지

1. **폐허의 마트** — 보급품 6개를 모으면 허공에 동그란 유리창이 열립니다
2. **싱그러운 들판** — 고블린
3. **마수의 숲** — 고블린 + 슬라임
4. **폐성의 회랑** — 흑마법사의 3연발 탄막 추가
5. **마왕성** — 보스 **현상**. 체력 50% 이하에서 탄막이 굵어지고 소환이 늘어납니다

## 기술

의존성 없는 단일 HTML 파일입니다. Canvas 2D + 바닐라 JS로 작성했고, 빌드 과정이 없습니다.
`index.html` 하나만 있으면 어디서든 호스팅됩니다.
