# 이세계전사 김대원

> 단기 4361년. 유례없는 핵전쟁으로 폐허가 된 대륙에서 두 발로 서 있는 유일한 생명체, 김대원.
> 빈 마트를 돌아다니며 연명하던 그의 눈앞에 알 수 없는 현상이 일어난다.
> 더는 볼 수 없는 싱그러운 들판이 비치는 동그란 유리창에 손을 대는 순간 —

브라우저에서 바로 돌아가는 세로형 탑다운 액션 게임입니다. 휴대폰과 PC 모두 지원합니다.

**▶ [지금 플레이하기](https://mincho-dan.github.io/sand-box/isekai-kimdaewon/)**

## 조작

| | 모바일 | PC |
|---|---|---|
| 이동 | 왼쪽 화면을 끌어서 (가상 스틱) | `WASD` / 방향키 |
| 공격 | `공격` 버튼 | `J` / `Space` |
| 회피 | `회피` 버튼 | `K` (또는 `Shift`) |
| 진행 | 화면 탭 | `Enter` |
| 소리 | 타이틀의 `소리` 버튼 | `M` |

소리 버튼은 **소리 켜짐 → 효과음만 → 소리 꺼짐** 3단계로 순환합니다.
세로 화면 그대로 한 손으로 즐길 수 있습니다.

## 게임 규칙

- **허기**가 계속 줄어듭니다. 0이 되면 체력이 깎이니 통조림·식량을 챙기세요.
- **회피는 허기를 소모합니다.** 무적 시간이 있는 대신 남발할 수 없습니다.
- **탄막은 무기로 쳐낼 수 있습니다.** 회피가 늦었다면 휘두르세요.
- 공격은 사거리 안의 가장 가까운 적을 **자동으로 조준**합니다.

## 무기

기본 무기는 **파이프 렌치**입니다. 배터리를 쓰지 않고 무한히 휘두를 수 있습니다.

**버려진 광산**부터 전동공구가 등장합니다. 전동공구는 휘두를 때마다 **공용 배터리**를 소모하고,
방전되면 자동으로 렌치로 돌아갑니다. 배터리는 적이 떨어뜨리며, **전동공구가 없어도 계속 쌓이므로**
나중에 공구를 주우면 바로 쓸 수 있습니다.

| 무기 | 공격력 | 사거리 | 배터리 소모 | 완충 시 스윙 |
|---|---|---|---|---|
| 파이프 렌치 | 16 | 보통 | 없음 | 무한 |
| 전동드라이버 | 26 | 보통 | 보통 | 20회 |
| 전기톱 | 34 | **상** | **상** | 9회 |
| 해머드릴 | 42 | 보통 | **상** | 10회 |
| 그라인더 | 38 | 하 | 하 | 25회 |

전동공구는 오래 쓰는 무기가 아니라 **위험한 순간에 꺼내 쓰는 자원**입니다.

## 점수

```
최종 점수 = 처치 점수 + 보급품 + 클리어 시간 보너스
```

- **처치 점수** — 적마다 다릅니다. 슬라임 60, 고블린 100, 분열체 150,
  흑마법사 180, 돌진병 220, 마왕 1500. 스테이지 카드에서 확인할 수 있습니다.
- **보급품** — 마트에서 줍는 보급품 1개당 50점.
- **시간 보너스** — 마왕을 쓰러뜨렸을 때만 붙습니다. 3000점에서 시작해 10초마다 100점씩 줄어듭니다.

게임이 끝나면 결과 화면에 항목별 내역이 표시됩니다.

## 성장

스테이지를 클리어하면 **보급 상점**이 열립니다. 마정석으로 다섯 가지를 각 4레벨까지 강화할 수 있습니다.

| 항목 | 레벨당 효과 |
|---|---|
| 최대 체력 | +20 |
| 최대 허기 | +20, 감소 속도 -10% |
| 렌치 공격력 | +4 |
| 공격 속도 | 쿨다운 -0.04초 |
| 회피 | 쿨다운 -0.1초, 허기 소모 -0.5 |

업그레이드는 **한 판 동안만** 유지됩니다. 죽으면 처음부터입니다.

## 스테이지

1. **폐허의 마트** — 보급품 6개를 모으면 허공에 동그란 유리창이 열립니다
2. **싱그러운 들판** — 고블린
3. **마수의 숲** — 슬라임 추가
4. **버려진 광산** — 돌진병 추가. 조준선이 뜨면 옆으로 피하세요
5. **폐성의 회랑** — 흑마법사의 3연발 탄막 추가
6. **얼어붙은 호수** — 분열체 추가. 쓰러뜨리면 둘로 갈라집니다
7. **마왕성 앞마당** — 지금까지의 적이 전부 나옵니다
8. **마왕성** — 보스 **현상**. 체력 절반 아래에서 탄막이 굵어지고 소환이 늘어납니다

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 테스트
npm run build    # 타입 검사 + 프로덕션 빌드
```

의존성은 **런타임 0개**입니다. Vite·TypeScript·vitest는 개발 도구일 뿐이고
빌드 결과는 정적 파일 두 개(HTML + JS)입니다.

```
src/
  config.ts        해상도·색·테마·랭킹 설정
  types.ts         공용 타입
  data/            챕터·적·무기·업그레이드 정의
  core/            상태, 맵, 입력, 저장, 파티클
  systems/         전투, 적 AI, 아이템, 상점, 랭킹, UI, 업데이트 루프
  render/          맵·엔티티·HUD·화면
  audio/           효과음, 배경음악
  ui/              랭킹 등록 폼 (DOM)
tests/             vitest
```

`main` 에 푸시하면 GitHub Actions 가 테스트 → 빌드 → Pages 배포까지 수행합니다.

### 화면 규격

논리 해상도는 540×972 고정입니다. 상단 108px는 정보바 전용 공간이고
나머지 540×864(15×24 타일)가 아레나라, 체력·허기 표시가 맵을 가리지 않습니다.

표시 크기는 실행 시 픽셀 단위로 계산해 어떤 화면 비율에서도 잘리지 않게 맞춥니다.
(`100vh`는 모바일 주소창 때문에 실제 보이는 높이보다 크고, `aspect-ratio`도 높이가 확정된
상태에서는 `max-width` 클램프에 비율이 깨져서 둘 다 쓰지 않습니다.)

### 입력 게이트

씬이 전환되는 순간에는 짧은 입력 잠금이 걸립니다. 보스를 잡으려고 연타하던 손가락이
엔딩 화면을 그대로 넘겨버리거나, 상점에서 원치 않는 업그레이드가 결제되는 것을 막습니다.
공격·회피 버튼은 어떤 경우에도 씬을 진행시키지 않습니다.

## 랭킹 (선택)

`src/config.ts` 의 `SUPABASE_URL` / `SUPABASE_ANON_KEY` 를 채우면 전역 랭킹이 켜집니다.
비워두면 게임은 그대로 동작하고 최고 점수만 브라우저에 저장됩니다.

1. [supabase.com](https://supabase.com) 에서 프로젝트 생성
2. SQL Editor 에 [`supabase.sql`](supabase.sql) 을 붙여넣고 Run
3. Project Settings → API 에서 **Project URL** 과 **anon public** 키를 복사해 `src/config.ts` 에 붙여넣기

> **`service_role` / `secret` 키는 절대 넣지 마세요.** RLS 를 통째로 우회하는 비밀키입니다.
> `anon`(`publishable`) 키는 방문자 브라우저에 어차피 노출되는 공개 키이고,
> 실제 보호는 RLS 정책이 담당합니다.

로그인은 없고 게임 오버 시 닉네임만 입력받습니다.
**닉네임당 최고 기록 1건만 유지**되며, 더 낮은 점수로 다시 등록하면 기존 기록이 그대로 남습니다.
이 정리는 DB 트리거가 담당하므로 클라이언트는 여전히 남의 기록을 지울 수 없습니다.

클라이언트에서 점수를 보내는 구조라 작정한 조작은 막을 수 없고,
SQL 의 CHECK 제약으로 비상식적인 값만 걸러냅니다.

## 소리

효과음과 배경음악 모두 **오디오 파일 없이** Web Audio 로 즉석 합성합니다.
배경음악은 16스텝 시퀀서가 베이스와 리드 두 성부를 연주하며,
메뉴 · 전투 · 보스전 세 패턴이 화면에 따라 바뀝니다.

시퀀서는 메인 루프에서 0.25초 앞을 미리 예약하는 방식이라 탭이 백그라운드로 가면
자연스럽게 멈춥니다. 모바일은 첫 터치 전까지 오디오가 잠겨 있어서 포인터 입력에서 컨텍스트를 깨웁니다.
