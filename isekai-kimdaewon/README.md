# 이세계전사 김대원

> 단기 4361년. 유례없는 핵전쟁으로 폐허가 된 대륙에서 두 발로 서 있는 유일한 생명체, 김대원.
> 빈 마트를 돌아다니며 연명하던 그의 눈앞에 알 수 없는 현상이 일어난다.
> 더는 볼 수 없는 싱그러운 들판이 비치는 동그란 유리창에 손을 대는 순간 —

브라우저에서 바로 돌아가는 세로형 탑다운 액션 게임입니다. 휴대폰과 PC 모두 지원합니다.

**▶ [지금 플레이하기](https://mincho-dan.github.io/sand-box/isekai-kimdaewon/)**

## 조작

| | 모바일 | PC |
|---|---|---|
| 이동 | 왼쪽 화면을 끌어서 (가상 스틱) | `WASD` / 방향키 |
| 공격 | `공격` 버튼 | `J` / `Space` |
| 회피 | `회피` 버튼 | `K` (또는 `Shift`) |
| 진행 | 화면 탭 | `Enter` |
| 소리 | 타이틀의 `소리` 버튼 | `M` |

소리 버튼은 **소리 켜짐 → 효과음만 → 소리 꺼짐** 3단계로 순환합니다.

세로 화면 그대로 한 손으로 즐길 수 있습니다. 화면을 돌릴 필요가 없습니다.

## 무기

기본 무기는 **파이프 렌치**입니다. 배터리를 쓰지 않고 무한히 휘두를 수 있습니다.

**버려진 광산**부터 전동공구가 등장합니다. 전동공구는 휘두를 때마다 **공용 배터리**를 소모하고,
방전되면 자동으로 렌치로 돌아갑니다. 배터리는 적이 떨어뜨리며, **전동공구가 없어도 계속 쌓이므로**
나중에 공구를 주우면 바로 쓸 수 있습니다.

| 무기 | 공격력 | 사거리 | 배터리 소모 |
|---|---|---|---|
| 파이프 렌치 | 16 | 보통 | 없음 |
| 전동드라이버 | 26 | 보통 | 보통 |
| 전기톱 | 34 | **상** | **상** |
| 해머드릴 | 42 | 보통 | **상** |
| 그라인더 | 38 | 하 | 하 |

## 게임 규칙

- **허기**가 계속 줄어듭니다. 0이 되면 체력이 깎이니 통조림·식량을 챙기세요.
- **회피는 허기를 소모합니다.** 무적 시간이 있는 대신 남발할 수 없습니다.
  회피 업그레이드를 올리면 소모량이 줄어듭니다.
- **탄막은 렌치로 쳐낼 수 있습니다.** 회피가 늦었다면 휘두르세요.
- 공격은 사거리 안의 가장 가까운 적을 **자동으로 조준**합니다.
- 적을 처치하면 **마정석**과 함께 확률적으로 식량·구급킷이 나옵니다.

## 성장

스테이지를 클리어하면 **보급 상점**이 열립니다. 마정석으로 다섯 가지를 각 4레벨까지 강화할 수 있습니다.

| 항목 | 레벨당 효과 |
|---|---|
| 최대 체력 | +20 |
| 최대 허기 | +20, 감소 속도 -10% |
| 렌치 공격력 | +4 |
| 공격 속도 | 쿨다운 -0.04초 |
| 회피 | 쿨다운 -0.1초, 무적 +0.03초 |

업그레이드는 **한 판 동안만** 유지됩니다. 죽으면 처음부터입니다. 최고 점수만 브라우저에 기록됩니다.

## 스테이지

1. **폐허의 마트** — 보급품 6개를 모으면 허공에 동그란 유리창이 열립니다
2. **싱그러운 들판** — 고블린
3. **마수의 숲** — 슬라임 추가
4. **버려진 광산** — 돌진병 추가. 조준선이 뜨면 옆으로 피하세요
5. **폐성의 회랑** — 흑마법사의 3연발 탄막 추가
6. **얼어붙은 호수** — 분열체 추가. 쓰러뜨리면 둘로 갈라집니다
7. **마왕성 앞마당** — 지금까지의 적이 전부 나옵니다
8. **마왕성** — 보스 **현상**. 체력 절반 아래에서 탄막이 굵어지고 소환이 늘어납니다

각 스테이지 시작 전 카드에서 목표와 신규 적의 특성을 확인할 수 있습니다.

## 랭킹 (선택)

`index.html` 상단의 `SUPABASE_URL` / `SUPABASE_ANON_KEY` 를 채우면 전역 랭킹이 켜집니다.
비워두면 게임은 그대로 동작하고 최고 점수만 브라우저에 저장됩니다.

1. [supabase.com](https://supabase.com) 에서 프로젝트 생성
2. SQL Editor 에 [`supabase.sql`](supabase.sql) 을 붙여넣고 Run
3. Project Settings → API 에서 **Project URL** 과 **anon public** 키를 복사해
   `index.html` 상단 두 상수에 붙여넣기

> **`service_role` 키는 절대 넣지 마세요.** 모든 권한을 우회하는 비밀키입니다.
> `anon` 키는 방문자 브라우저에 어차피 노출되는 공개 키이고, 실제 보호는 RLS 정책이 담당합니다.

로그인은 없고 게임 오버 시 닉네임만 입력받습니다. 클라이언트에서 점수를 보내는 구조라
작정한 조작은 막을 수 없고, SQL 의 CHECK 제약으로 비상식적인 값만 걸러냅니다.

## 소리

효과음과 배경음악 모두 **오디오 파일 없이** Web Audio 로 즉석 합성합니다.
효과음은 오실레이터와 노이즈 버퍼에 게인 엔벨로프를 건 것이고,
배경음악은 16스텝 시퀀서가 베이스와 리드 두 성부를 연주합니다.
메뉴 · 전투 · 보스전 세 가지 패턴이 화면에 따라 바뀝니다.

시퀀서는 메인 루프에서 0.25초 앞을 미리 예약하는 방식이라, 탭이 백그라운드로 가면
자연스럽게 멈춥니다. 모바일은 첫 터치 전까지 오디오가 잠겨 있어서 포인터 입력에서 컨텍스트를 깨웁니다.

## 기술

의존성 없는 단일 HTML 파일입니다. Canvas 2D + 바닐라 JS로 작성했고 빌드 과정이 없습니다.
`index.html` 하나만 있으면 어디서든 호스팅됩니다.

논리 해상도는 540×972 고정입니다. 상단 108px는 정보바 전용 공간이고 나머지 540×864(15×24 타일)가
아레나라, 체력·허기 표시가 맵을 가리지 않습니다.

표시 크기는 실행 시 픽셀 단위로 계산해 어떤 화면 비율에서도 잘리지 않게 맞춥니다.
(`100vh`는 모바일 주소창 때문에 실제 보이는 높이보다 크고, `aspect-ratio`도 높이가 확정된 상태에서는
`max-width` 클램프에 비율이 깨져서 둘 다 쓰지 않습니다.)

씬이 전환되는 순간에는 짧은 **입력 잠금**이 걸립니다. 보스를 잡으려고 연타하던 손가락이
엔딩 화면을 그대로 넘겨버리거나, 상점에서 원치 않는 업그레이드가 결제되는 것을 막기 위한 장치입니다.
